口径说明

指数基金：点位为对应指数最新收盘点位，市盈率为指数滚动市盈率（PE TTM，市值加权）。当前 PE 低于买入线提示「买入时机」，高于卖出线提示「卖出时机」，介于二者之间提示「持有观望」。数据由 GitHub Actions 每日定时（约 09:15、20:15 北京时间）自动登录 wglh 抓取并更新。

A股股票：通过 AKShare 抓取全市场财务数据，按粗筛（连续5年ROE>20%、净利润现金含量>80%、毛利率>40%）+细筛（5年平均现金含量≥100%、资产负债率<60%、分红率≥25%）筛选候选股；买入需同时满足深证A股PE<20、个股TTM PE<15、动态股息率>十年国债收益率；卖出为个股PE>50或股息率<国债收益率1/3。PE由累计EPS推算TTM，股息率为过去12个月分红/当前价。

本工具仅用于个人估值记录，不构成任何投资建议。市场有风险，决策需谨慎。
